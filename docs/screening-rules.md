# Screening rules (example)

A generic example of the rules Screen agents apply. Replace them with your own criteria. A posting is
recommended only if no category below says "not recommended".

## 1. Level
- Recommended: new-grad, entry-level, junior, early-career and internship-to-full-time roles.
- Not recommended: senior, staff, principal, lead and manager roles; JDs requiring more than 2 years of experience.

## 2. Direction
- Recommended: software engineer, machine learning engineer, applied scientist, NLP and LLM roles.
- Not recommended: non-technical roles (sales, recruiting, marketing, support) and pure hardware or embedded roles.

## 3. Location and status
- Recommended: on-site, hybrid or remote roles in the target country.
- Not recommended: roles outside the target country, or roles that require security clearance or a citizenship the applicant lacks.

## 4. Timing
- Recommended: postings that are still open and whose start date fits the applicant's availability.
- Not recommended: closed postings, and roles starting well before or after the availability window.

## 5. Other
- Not recommended: staffing-agency reposts without a named employer, and postings with no usable JD.
- Cases these rules do not cover are judged by the stated goal: a technical entry-level role the applicant could realistically get.
